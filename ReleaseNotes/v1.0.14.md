# iBestSpeech 1.0.14

Four pronunciation fixes, all measured against the built engine first.

**LLM and LLMs name every letter.** The rules collapse the doubled L
("llama" needs that; initials don't), so "LLMs" read "ell-em-ess". Spaced
letters follow the file's own convention (MIDI, HDMI).

**Y'all stays one syllable.** The apostrophe split it into "yuh-all";
plain "yawl" is byte-identical to "yall" on every English build, which is
the wanted sound. Both casings.

**Full-width punctuation folds to ASCII.** A full-width question mark made
the 1995 build return no audio at all for the whole phrase — which is how
a notification lost everything after its Chinese run. U+FF01–U+FF5E now
fold in the same pass as the other typographic forms.

**Ubuntu is "oo boon too" again.** The source had drifted to "too boon
too" while the shipped build still carried the right reading; regenerating
restores it with no behavior change.

Verified by the SSML suite (170 checks) and the engine word-path probes
behind each entry.
