# iBestSpeech 1.0.7

Four faults reported from use, each reproduced and fixed where the fault
actually was.

## What changed

**The tail after a comma is spoken.** On all thirteen 2006 builds a comma ends
the text: "Reddit, Yesterday" was byte-identical to "Reddit" alone, which is
why "Reddit, Yesterday, Version 2026.38.0" spoke only its first word. The text
layer now rewrites a user-written comma as a colon -- the same short pause,
and byte-identical where the comma already worked -- unless a digit sits
immediately either side, so "1,000" and "5,19" keep their commas.

**Version strings like 2026.38.0 are read.** A decimal with a four-or-more
digit whole part made no sound at all on 19 of 20 builds and took the rest of
the utterance with it. The engine patch reads the whole part as one number
and spells the fraction ("123.45" is byte-identical before and after);
anything past a second stop is given back, so "2026.38.0" ends "... point
three eight" with ".0" read on its own.

**"email" is split like "Email" already was.** The dictionary had the
capitalized form but not the lowercase one the engine reads as a single odd
word; "ebook" and "ecommerce" had the same gap. All three now read with the
stress on the E, verified on the engine's own audio on all three English
builds.

**Latin text never switches an English voice.** The Photos heading was read in
a French voice because "photos" is a French word. A Latin detection is a guess
about shared words, never proof, so an English voice now stays put; only a
unique script -- Russian, Greek, Japanese, Arabic, Hebrew -- still switches.
Switching between non-English voices is unchanged.

## Verified

Engine regression tests 78/78, plus 9 new checks for the version fault (which
fail on the unpatched tree, as required).
The oracle of the original Keynote DLLs' answers: 4906 identical, 0
differing.
App-side Swift tests 140/140; language detection 64/64; engine parameters
15/15.
Every dictionary entry checked against the engine's own audio on all three
English builds: 132 terms, none wasted, none silent.
CI green, including the Xcode app build and the XCFramework.
