# iBestSpeech 1.0.6

Three faults reported from use, each reproduced and fixed where the fault
actually was.

## "84 degrees" was read as "84 degree"

The character pass says what a symbol *is*, and the standard the emoji
descriptions come from gives the **singular** noun for the degree sign. Put a
number in front of it and you got "84 degree".

The plural forms are not in those descriptions — they live in the same standard's
units data, which is now read into the app. A unit symbol directly after a number
reads in that number's **plural form**, and the form is chosen by that language's
own plural rule rather than by "is the number 1". That distinction is the whole
point:

- French uses the singular for **zero** — "0 degre"
- Polish has one/few/many — "22 stopnie", "5 stopni"
- Russian has one/few/many — "3 градуса", "5 градусов"
- Arabic has a **dual** — "2 درجتان"
- Japanese has only one form — "84 度"

All thirteen languages are verified. **Currency symbols had the identical fault**
— five euro was "5 euro" — and are fixed the same way.

## "Facebook" was read as one odd word

The engine does not split camel case: the audio for "Facebook" is byte-for-byte
the same as for "facebook", so it came out as a single unknown word instead of
"Face Book". This is exactly the FaceTime fault, and the dictionary already
handled FaceTime, iPhone, iPad, iCloud, AirDrop and GitHub this way — the brands
below were simply missing.

18 added, each verified **on the audio the engine produces**, on all three
English builds: the spaced form must produce different audio from the joined
form, and must not be silent.

Facebook, Instagram, WhatsApp, YouTube, LinkedIn, TikTok, Snapchat, MacBook,
ApplePay, AppleCare, HomePod, Safari, Spotify, Netflix, Discord, Reddit,
Wikipedia, PlayStation.

The dictionary is now 129 entries, and a check confirms every one changes the
reading, none is silent, and none is a no-op.

## An App Store line was read as Dutch

"Buy now, pay over time, Yesterday, Version 4.98.2 * 129.2 MB" was spoken in a
Dutch voice. "over" is a Dutch word, and it was the **only** word in the line
that matched anything — one hit in five words, which the detector accepted.

A single word of evidence is now accepted only when it is a real share of the
text. That keeps short greetings working ("Hallo", "Bonjour") and refuses the
sentence case. Genuine text in Spanish, French, German, Italian, Dutch,
Portuguese and Polish is still detected, and is tested to be.

**The voice switches far less often now, and that is the point.** Eight App Store
and interface lines are asserted never to be read as another language.
