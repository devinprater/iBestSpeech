# iBestSpeech 1.0.12

**This release works differently from every previous one: it ships no voice
data. You supply the Keynote Gold file.**

## Why

The voice data these voices speak with is not ours. It belongs to Berkeley
Systems and HumanWare, and it was never ours to hand out — every release up to
1.0.11 carried it anyway. That is over. The engine code is MIT and ships; the
tables stay behind.

## What you do

On first launch the app asks for a file. On Windows, Keynote Gold installs:

- `B32_TTS.DLL` — the 1995 English voice
- `dll_eng.dll`, `dll_rus.dll`, `dll_jpn.dll`, … — the 2006 voices (12 languages)

Copy one onto the phone any way you like — Files, AirDrop, iCloud Drive, a
cable — then pick it in the app. The app reads the file, works out which voice
it is, and adds it. That is the whole setup.

The 1998 voices (`KGMENG.DLL`) additionally need their shared core
`KNGMM.DLL`. The app says so when it sees one, rather than failing quietly.

## How it knows which voice you gave it

Not by the file name, and not by whether the file opens. The engine will
happily open a 2006 English file *as all thirteen 2006 voices and 1995 at once*
— one file, fourteen accepted answers, and only one of them that actually
speaks. So the app decides by **sound**: it asks each candidate to say
something and keeps the one that produces audio. Verified against the real
original DLLs: every voice resolves to exactly one correct answer, and a file
that is not an engine file at all — zeros, random bytes, a text document — is
refused instead of guessed at.

## What is still the same

Everything you already had. Text cleaning, the pronunciation dictionary, emoji
and unit handling, language detection, SSML, pitch and rate — untouched. The
voices sound exactly as they did, because it is the same engine and the same
data, just read from your file instead of from a table compiled into the app.

## If you want the old one

A build with the tables compiled in is still produced, because the author
installs it on his own device. It is **not** attached to this release and it is
not for distribution.
